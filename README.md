# OpenStreak

Трекер задач, привычек и целей с сериями, «идеальными днями» и итогом дня.
Работает офлайн, все данные хранятся на устройстве.

**Стек:** Expo SDK 58 · React Native 0.88 · TypeScript · zustand

## Запуск

```bash
npm install
npm start          # Expo dev server
npm run android    # или ios / web
```

### Веб-режим для разработки

```bash
npm run web        # откроет http://localhost:8081
```

Интерфейс можно проверять в браузере на ПК: на широком окне приложение показывается в колонке
шириной с телефон (`src/app/WebFrame.tsx`), данные хранятся в `localStorage` браузера.
Уведомления, вибрация, выбор даты и экспорт файлов на вебе не работают или работают упрощённо —
их проверяйте на телефоне.

Каталог компонентов «Мульта» (только в разработке): `http://localhost:8081/?catalog` на вебе или
`EXPO_PUBLIC_CATALOG=1 npx expo start` для телефона.

### Нативная сборка

Напоминания и (в будущем) геозоны требуют dev-сборки — в Expo Go они работают не полностью:

```bash
npx expo run:android                                     # локально (нужен Android Studio)
npx eas build --profile development --platform android   # или в облаке EAS
```

### Виджеты

Виджет «Сегодня» — большой (список дел, «Сделано · N», «+») и средний (счёт дня и три ближайших
дела, долг первым; когда всё сделано — «Закрыть день»), в «Обычном» и «Мульте». Макет —
`design/widgets/today-L-M.png`.

- **Android** — `react-native-android-widget`: виджет рисуется SVG и обычными блоками, нажатие
  открывает приложение, «+» и «Закрыть день» — по ссылкам `openstreak://widget/add` и
  `openstreak://widget/review`. Работает только в dev-сборке (`npx expo run:android`).
- **iOS** — `expo-widgets` (SwiftUI). Нужна dev-сборка на Mac; в `app.json` задан
  `ios.bundleIdentifier`, группа и идентификатор расширения берутся от него.
- **Отметка из виджета (Android):** тап по кружку в строке отмечает дело или привычку, не открывая
  приложение (привычка — полная норма). Анимации у виджета Android нет, поэтому отметка — два кадра:
  строка «защёлкивается» (залитая отметка с галочкой, в «Мульте» луна становится полной), через 0,7 с
  уходит из списка. Отменить отметку можно только в приложении; на iOS нажатие
  на строку открывает приложение.
- **Добавить виджет из приложения (Android):** «Настройки» → «Виджеты» → «Добавить» показывает окно
  лаунчера; если лаунчер так не умеет, появляется подсказка про долгое нажатие на экран.
- В Expo Go и в вебе виджетов нет, приложение работает без них.
- Виджет обновляется, когда приложение открыто или данные меняются. Пока оно закрыто, Android
  перерисовывает виджет раз в 30 минут (так он подхватывает смену суток), iOS показывает
  последний снимок.

## Проверки

```bash
npm run check           # typecheck + lint + тесты + контраст
npm run format          # Prettier
npm run check:contrast  # WCAG-контраст всех пар цветов обеих тем
```

## Структура

```
src/
  app/          корневой компонент, запуск, настройки → тема и тон
  navigation/   вкладки Сегодня · Дела · Привычки · Цели · Стая и экраны поверх них
  features/     экраны: сегодня, дела, привычки, цели, стая, итог дня, настройки, шторка «Новое»
  ui/           компоненты «Мульта» (только на токенах) и каталог
  core/         ядро: модель данных v2, хранилище, миграция, операции, дни, серии, очки,
                план напоминаний — чистая логика с тестами
  store/        тема и тон для интерфейса (копия настроек из данных)
  services/     уведомления, экспорт/импорт, вибро, ключи на устройстве
  i18n/         строки (тон «обычный / пацанский», формы множественного числа)
  theme/        палитры «Дня» и «Вечернего мульта», шрифты, метрики, наклейка
  widgets/      виджет «Сегодня»: вид (тексты и цвета), SVG, раскладки Android и iOS
scripts/        служебные скрипты (проверка контраста)
```
